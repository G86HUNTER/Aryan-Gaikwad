This website is designed for VIT Pune’s official first-year student council, Team Saarthi. Its goal is to introduce students to the club’s mission, working structure, and domains, while encouraging them to join and contribute.

The site opens with a dynamic greeting based on the time of day and a video background, giving it a modern, interactive feel. Visitors can explore Saarthi’s various functional domains — like Technical, Editorial, Marketing, Design, etc. — through an intuitive accordion interface. Each section briefly explains the role and impact of that domain.

A Presidents section highlights the leadership team with photos, while the Contact section connects users to Saarthi’s social media platforms (Instagram, LinkedIn, WhatsApp). There's also a Gallery preview that links to a separate media page showcasing past events.

The layout is responsive and built using Bootstrap 5, ensuring smooth viewing across devices. However, the website is still under development, with certain features and media (like gallery images or video files) yet to be finalized or hosted online.
